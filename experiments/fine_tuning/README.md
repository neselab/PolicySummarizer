# Fine-Tuning Records

This directory contains the dataset-generation scripts, JSONL training data,
job-launch scripts, checkpoints, and evaluation tables from the fine-tuning
experiments.

The files preserve the provider-specific model identifiers and configuration
used for those runs. They are separate from the current PolicySummarizer
runtime and from the maintained sample-size and Z3 protocols.

`legacy/root_snapshot/` preserves distinct pre-restructure scripts and run
records that differed from the consolidated directory.
